## 변경 요약

- 무엇을 왜 변경했나요?

## 검증

- 어떤 테스트를 실행했나요?
- 어떤 `AGENTS.md`와 프로젝트별 지침을 따랐나요?

## 제품 및 디자인 영향

- 사용자 동작, 스크린샷 또는 게임 플레이 캡처, 다국어 문서, 접근성, 프로젝트별 UI·디자인 규칙에 미치는 영향을 적어 주세요. 해당하지 않으면 “없음”이라고 적어 주세요.

## 권한 및 데이터

- 권한, 수집 필드, 배포, 릴리스 또는 시크릿 변경을 설명해 주세요. 예시에는 가상 데이터를 사용해 주세요.
