# Oddmash에 기여하기

[English](../../CONTRIBUTING.md) · **한국어** · [日本語](../ja/CONTRIBUTING.md) · [简体中文](../zh-CN/CONTRIBUTING.md)

더 나은 개발 도구를 만드는 데 함께해 주셔서 감사합니다.

## 문제 보고

관련 프로젝트에 이슈를 등록해 주세요. 기대한 동작, 실제 동작, 재현 절차와 함께 프로젝트 버전 및 관련 환경을 알려 주세요. 공개 또는 로컬 테스트 페이지와 가상 데이터를 사용해 주세요. 로그와 스크린샷에서 인증 정보, 비공개 페이지 내용, 개인 데이터를 제거해 주세요.

## 변경 제안

새 기능이나 프로젝트의 여러 부분에 영향을 주는 변경은 이슈를 먼저 열어 주세요. 작은 수정은 풀 리퀘스트를 열고 어떤 동작이 달라지는지 설명해 주세요.

## 프로젝트 README 작성 기준

- README는 서비스 소개 페이지로 작성합니다. 첫 부분에서 무엇을 하는 서비스인지, 누구에게 도움이 되는지, 어떤 상황에 쓰는지 사례 하나로 보여 주세요.
- 스크린샷, 짧은 녹화 또는 데모로 서비스 사용 모습을 보여 주세요. 이미지에 설명이 담긴 대체 텍스트를 넣고, 예시 이미지는 예시라고 표시해 주세요. 시각 자료에는 샘플 데이터를 사용해 주세요.
- 저장소 설정, 설치, 로컬 실행 명령, 구현 설명, 빌드, 테스트, 릴리스, 기여 절차는 README에 넣지 마세요.
- 개발과 검증에 관한 모든 안내는 프로젝트의 `CONTRIBUTING.md`에 작성하세요. 필요하면 README 하단에서 짧게 링크합니다.
- 한국어·일본어·중국어 간체·영어 버전의 내용, 언어 이동 링크, 시각 자료를 함께 갱신해 주세요.

## 풀 리퀘스트 제출

- 변경 범위를 좁게 유지하고, 관련 이슈가 있다면 링크를 추가해 주세요.
- 프로젝트의 `CONTRIBUTING.md`에 따라 개발 환경을 설정하고 검사를 실행해 주세요. 풀 리퀘스트에 결과를 적어 주세요.
- 권한, 수집 데이터, 공개 API의 변경 사항을 설명해 주세요.
