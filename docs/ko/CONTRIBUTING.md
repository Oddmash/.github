# Oddmash에 기여하기

[English](../../CONTRIBUTING.md) · **한국어** · [日本語](../ja/CONTRIBUTING.md) · [简体中文](../zh-CN/CONTRIBUTING.md)

더 나은 개발 도구를 만드는 데 함께해 주셔서 감사합니다.

## 문제 보고

관련 프로젝트에 이슈를 등록해 주세요. 기대한 동작, 실제 동작, 재현 절차와 함께 프로젝트 버전 및 관련 환경을 알려 주세요. 공개 또는 로컬 테스트 페이지와 가상 데이터를 사용해 주세요. 로그와 스크린샷에서 인증 정보, 비공개 페이지 내용, 개인 데이터를 제거해 주세요.

## 변경 제안

새 기능이나 프로젝트의 여러 부분에 영향을 주는 변경은 이슈를 먼저 열어 주세요. 작은 수정은 풀 리퀘스트를 열고 어떤 동작이 달라지는지 설명해 주세요.

## 풀 리퀘스트 제출

- 변경 범위를 좁게 유지하고, 관련 이슈가 있다면 링크를 추가해 주세요.
- 프로젝트 README에 따라 개발 환경을 설정하고 검사를 실행해 주세요. 풀 리퀘스트에 결과를 적어 주세요.
- 권한, 수집 데이터, 공개 API의 변경 사항을 설명해 주세요.
