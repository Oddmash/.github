## 変更概要

- 何を変更しましたか。変更した理由は何ですか。

## 検証

- どのようなテストを実行しましたか。
- どの `AGENTS.md` とプロジェクト固有のガイドに従いましたか。

## プロダクトとデザインへの影響

- ユーザー向けの動作、スクリーンショットまたはゲームプレイのキャプチャ、ローカライズ、アクセシビリティ、プロジェクト固有の UI・デザイン規則への影響を記載してください。該当しない場合は「なし」と記載してください。

## 権限とデータ

- 権限、収集項目、デプロイ、リリース、シークレットの変更があれば記載してください。例にはダミーデータを使ってください。
