# Oddmash へのコントリビューション

[English](../../CONTRIBUTING.md) · [한국어](../ko/CONTRIBUTING.md) · **日本語** · [简体中文](../zh-CN/CONTRIBUTING.md)

開発ツールの改善にご協力いただきありがとうございます。

## 不具合を報告する

該当するプロジェクトで Issue を作成し、期待した動作、実際の動作、再現手順を記載してください。プロジェクトのバージョンと関連する環境情報も添えてください。公開またはローカルのテストページとダミーデータを使い、ログやスクリーンショットから認証情報、非公開ページの内容、個人データを除いてください。

## 変更を提案する

新機能やプロジェクトの複数箇所に及ぶ変更は、まず Issue を作成してください。小さな修正はプルリクエストを作成し、どの動作が変わるかを説明してください。

## プルリクエストを提出する

- 変更範囲を絞り、関連する Issue があればリンクしてください。
- プロジェクトの README に従って環境を準備し、チェックを実行してください。結果はプルリクエストに記載してください。
- 権限、収集データ、公開 API の変更点を説明してください。
